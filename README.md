# ty

Fast explicit-state and symbolic model checker with certified proofs, for TLA+, Petri nets, and hardware designs. Inspired by TLC.

ty is made by [ALab](https://alab.systems). Its source code is not published:
this repository carries ty's binary releases, their release notes, and its
license.

## Install

Install it with aterm's package manager, which verifies every signed binary:

```sh
aterm pkg install ty
```

Every release is listed under [Releases](https://github.com/alabsystems/ty/releases),
and its notes are in `release-notes/`.
